# AURA DESIGN SYSTEM

**Product:** AURA
**Document:** Design System
**Version:** 1.0
**Status:** Approved working direction

---

# 1. DESIGN VISION

AURA should feel like a combination of:

* premium fashion editorial
* modern consumer technology
* intelligent personal assistant
* visual creativity tool

It should not resemble:

* enterprise software
* analytics dashboards
* generic AI chat applications
* shopping marketplaces
* technical AI tooling

---

# 2. DESIGN ATTRIBUTES

AURA should be:

* premium
* minimal
* editorial
* immersive
* image-first
* calm
* expressive
* modern
* Gen-Z compatible
* sophisticated

---

# 3. VISUAL HIERARCHY

The hierarchy should generally be:

```text
Photography
↓
Outfit
↓
Primary action
↓
Context
↓
Supporting information
```

The interface should never overpower the fashion imagery.

---

# 4. COLOR SYSTEM

## Primary foundation

Deep neutral / near-black.

## Secondary

Warm white / off-white.

## Accent

Restrained lavender.

The accent should be used for:

* selection
* primary interactive states
* subtle highlights
* focus
* progress

It should not fill the entire interface.

---

# 5. SURFACES

Primary:

```text
Deep neutral background
```

Secondary:

```text
Elevated neutral surface
```

Glass surfaces:

Used selectively for:

* floating controls
* contextual overlays
* navigation
* transient controls

Do not make every surface glass.

---

# 6. TYPOGRAPHY

AURA needs two primary typographic personalities.

## Editorial

Used for:

* major fashion moments
* hero statements
* contextual headlines

## Interface

Used for:

* buttons
* labels
* metadata
* settings
* functional content

Typography should have strong hierarchy with minimal text.

---

# 7. TYPE SCALE

Conceptual scale:

```text
Display
Large headline
Headline
Title
Body
Secondary
Caption
Metadata
```

Display sizes should be reserved for high-value moments.

Avoid large text everywhere.

---

# 8. IMAGE SYSTEM

Images are first-class product content.

Preferred:

* edge-to-edge photography
* large garment imagery
* large outfit imagery
* portrait-oriented fashion imagery
* clean transparent garment assets

Avoid excessive image cropping when garment details matter.

---

# 9. GARMENT CARDS

Garment cards should prioritize:

1. garment image
2. garment name
3. optional minimal metadata

Avoid:

* excessive tags
* percentages
* technical AI labels

---

# 10. OUTFIT COMPOSITIONS

Outfit compositions should be visually cohesive.

Potential structure:

```text
Complete outfit
        ↓
Individual garment references
        ↓
Actions
```

The complete look should always remain visually dominant.

---

# 11. MIX & MATCH COMPONENT

The Mix & Match selector should feel like a fashion editor.

Core behavior:

* horizontal swiping
* immediate visual update
* selected item clearly indicated
* minimal labels
* smooth transitions

---

# 12. AI CONTEXT COMPONENT

AURA's conversational elements should be visually subtle.

Example:

> Dinner tonight?
> Let's get you dressed.

The message should feel like a personal suggestion, not a chat window.

---

# 13. BUTTON LANGUAGE

Primary actions should use direct language:

* Create
* Change
* Try on
* Save
* Wear
* Share
* Add
* Explore

Avoid:

* Generate AI
* Execute
* Process
* Analyze
* Run model

---

# 14. ICONOGRAPHY

Icons should be:

* simple
* modern
* consistent
* lightweight

Avoid emoji as primary navigation.

---

# 15. NAVIGATION

Navigation should be visually minimal.

Primary:

```text
Home
Closet
Create
Inspiration
Profile
```

Do not overload navigation with every capability.

---

# 16. LIQUID GLASS

Use Liquid Glass selectively.

Appropriate:

* floating bottom actions
* contextual controls
* temporary overlays
* media controls

Not appropriate:

* every card
* every section
* garment images
* large content backgrounds

---

# 17. MOTION

Motion should communicate state changes.

Important transitions:

### Garment replacement

Selected garment visually replaces the previous garment.

### Outfit generation

Subtle progressive reveal.

### Save

Clear but restrained confirmation.

### VTO

Generation state followed by visual reveal.

### Navigation

Fast, smooth and unobtrusive.

---

# 18. REDUCED MOTION

Every meaningful animation must have a reduced-motion equivalent.

No essential functionality may depend on animation.

---

# 19. LOADING

Loading states should be:

* elegant
* minimal
* honest

Example:

> Creating your look…

Do not invent fake technical progress.

Never show:

> Analyzing 97%...

unless a real measurable process supports it.

---

# 20. ERROR DESIGN

Errors should:

1. explain what happened
2. preserve user work
3. offer recovery

Example:

> We couldn't process that photo.

Actions:

> Try again

> Choose another photo

Never silently discard user input.

---

# 21. EMPTY STATES

Empty states should feel like invitations.

Instead of:

> No outfits found.

Use:

> Your next look starts here.

Action:

> Create an outfit

---

# 22. ACCESSIBILITY

AURA must support:

* sufficient contrast
* dynamic text
* accessible labels
* touch targets
* screen-reader semantics
* reduced motion
* keyboard/accessibility navigation where applicable

Fashion aesthetics must not compromise usability.

---

# 23. DESIGN PRINCIPLES

### 1. Photography is the UI.

### 2. AI should feel invisible.

### 3. User creativity should remain central.

### 4. Interfaces should disappear when the outfit needs attention.

### 5. Premium does not mean complicated.

### 6. Animation should communicate, not decorate.

### 7. Every visual element must have a purpose.

---

# 24. DESIGN ANTI-PATTERNS

Avoid:

* dashboard-heavy screens
* excessive cards
* excessive rounded rectangles
* excessive lavender
* technical AI labels
* giant metrics
* emoji navigation
* meaningless badges
* unnecessary charts
* notification overload
* excessive explanatory text
* fake AI confidence scores

---

# 25. DESIGN SYSTEM GOAL

AURA should be recognizable even without the logo.

The visual identity should come from:

* typography
* photography
* composition
* motion
* restrained color
* glass interaction
* editorial spacing

rather than decoration.
